## Testing Documentation

### 1. Test Cases

Documentation of test cases designed to validate application functionality.

Includes:
- Test Case ID
- Test Scenario
- Preconditions
- Test Steps
- Test Data
- Expected Results
- Actual Results
- Status (Pass / Fail)

[View Test Cases](./Test-Cases/)

### 2. Bug Reports

Examples of software defects identified during testing.

Each bug report includes:
- Bug ID
- Bug Title
- Description
- Environment
- Preconditions
- Steps to Reproduce
- Expected Result
- Actual Result
- Severity
- Priority
- Screenshots / Evidence
- Bug Status

[View Bug Reports](./Bug-Reports/)

### 3. Test Executions

Records of executed test cases and their results.

Includes:
- Test Execution ID
- Test Case ID
- Execution Date
- Test Environment
- Actual Results
- Execution Status
- Associated Bug Reports

[View Test Executions](./Test-Executions/)

### 4. Test Plans

Documentation describing the testing strategy, scope, objectives, resources, and testing approach.

[View Test Plans](./Test-Plans/)

### 5. Test Scenarios

High-level descriptions of functionalities and user flows that require testing.

[View Test Scenarios](./Test-Scenarios/)

### 6. API Testing

API testing documentation, including requests, responses, validation checks, and Postman collections.

[View API Testing](./API-Testing/)

### 7. SQL & Database Testing

Examples of SQL queries used to validate database records, data integrity, and expected results.

[View SQL Testing](./SQL-Testing/)
